## 1. スタート：大きなミルを作る

### 目指すのは、ディアボロ同士が離れた大きなミル

「いい入り方」の目安は、ホバーを広げたときにディアボロ同士が離れ、3個が大きなミルの形に入ることです。スタートを練習するときは、まず**広げたときに2個のディアボロが離れているか**を確認します。

慣れないうちに、小さくなったミルを途中から大きくするのは難しいものです。最初から大きく作り、その大きさを維持することを目指しましょう。

WSでは、ミルの形に自然に入るスタートと「アラタ外し」の2種類を実演しました。講師の感覚では、ミルの形になるように解く方が入りやすいです。

### 力を入れるのは「開く」「解く」の二段階

ラップを開くときも、解くときも、ディアボロを上げられます。この二段階で、1つ目・2つ目を上げる感覚です。

2ディアボロでハイトスやFTSに入るときの、ディアボロを上げるタイミングも手掛かりになります。細かなタイミングを言葉だけで合わせようとするより、まずは広げたときにディアボロ同士が離れる形を確認してください。

### 解く動きが1プッシュ目

解いてから押し始めるのではなく、**解く動きそのものを1プッシュ目**と考えます。

1. 解くときには、1つ目のディアボロが飛んできています。その下へ、解いたディアボロを潜り込ませるようにしっかり送ります。
2. 潜らせたら右手を引き戻し、浮いているディアボロを受け取ります。
3. 受け取ったディアボロを、次に飛んでくるディアボロの下を通るように送ります。

「二段階で上げる → 下に潜らせて送る → 右手を引き戻して受け取る」という流れを、実演の動きと合わせて思い出してみてください。

## 2. 押し方：作った大きさを維持する

ここでのゴールは、**スタートで作ったミルの大きさを維持すること**です。

### 右下で受けて、左へ送る

2ディアボロでは、右手の下あたりを縦に押すイメージを持つ人がいます。3ディアボロでは、それより腕を広く構え、ミルの面の右下あたりで受け取り、右下部分に沿って左へしっかり送り出すイメージです。

| 動き | WSで伝えたイメージ |
| --- | --- |
| 受け取る | ミルの面の右下あたりで受ける |
| 送り出す | ミルの右下部分に沿って左へ送る |
| 全体の形 | ミルを包み込む・抱え込む |

2ディアボロとの比較は、押す位置と送り出す方向の違いをつかむためのものです。2ディアボロの押し方が全員同じという意味ではありません。

### スティックの先で送り出す

どこに力をかけたいかを意識し、スティックの先で送り出します。

講師の感覚に近いのは、「スティックの先で引っ掻く」「バットやラケットで打つように、力をかけたいところに力が伝わるように振る」というイメージです。「包み込む・抱え込む」は、ミルの右下部分に沿って送る動きのイメージとして使っています。

これらは動きをつかむための比喩です。自分にしっくりくる表現を探してみてください。

### ゆっくり押せる大きさを保つ

基本はゆっくりしたテンポを目指します。そのためにも、ミルはある程度大きい方が練習しやすくなります。

講師の感覚では、しっかり押せるとミルが大きくなり、力のロスが少ない状態になります。まずはスタートで作った大きさを保てているかを見ましょう。

### 左手の動かし方

WSでは、シンクロ、アシンクロ、片手固定にも触れました。講師の考えとしては、最終的には複数の動かし方ができるようになることを勧めています。一方、利き手を固定する回し方は勧めていません。

## 3. 回り始めたら：長く、楽に回す

### プッシュ数より、長く回す

回り始めると、何回押せたかを数えたくなります。練習では、**どれだけ長く回せたか**に意識を向けてみてください。大きさを維持しながら回し続けることが目標です。

### 力みすぎず、全体を使う

最初は力みやすいものです。肩から手まで全体の力をまんべんなく使い、楽に回すことを意識します。

「スティックの先で送る」は力を伝える先の意識で、「肩から手まで使う」は体の使い方の意識です。ミルを抱え込む・包み込むようなイメージも手掛かりになります。

## 4. スタート位置と紐の長さのコツ

### 解く前のミルを少し左側に置く

スタート前のワンハンドウィンドミルを少し左側に置くと、左手を上へ動かして、ディアボロを右手側へ送りやすくなる、というのが講師の感覚です。

身体の中央から左上へ開くと、タイミングによってはディアボロが上へ飛び、右手側へ来ないことがあります。スタートのタイミングが惜しいときに試せる、補助的なコツです。必ずこの位置から始めなければならないわけではありません。

### 初学者には長めの紐を勧める

まだ目が慣れていない段階では、小さなミルの速いテンポに合わせるのが難しくなります。講師は、紐全体を使って大きなミルを作り、ゆっくりしたテンポで押すタイミングを練習するために、長めの紐を勧めています。

| 紐の長さ | ミルとテンポの傾向 | 押す力の感覚 |
| --- | --- | --- |
| 長め | 紐全体を使うと大きく作りやすく、テンポがゆっくりになる | より力が必要 |
| 短め | ミルが小さくなりやすく、テンポが速くなる | 長い場合より小さな力でよい |

長くするだけでなく、**紐全体を使って、スタートで大きく作ること**がポイントです。長さの合う目安は人によって違います。長い紐でも、スタートで大きなミルを作り、その状態を維持することを目指しましょう。

## 5. 自分の動画を撮って確認する

まずは、自分の動画を撮ってみてください。「こう動かしているつもり」と、実際の動きにはずれがあります。

最初に自分のイメージと映像を見比べ、そのうえで回せる人の動画と比較します。

- ホバーを広げたとき、ディアボロ同士が離れているか。
- 解く動きでしっかり送り出せているか。
- 受け取る位置と、送り出す方向はどうなっているか。
- スタートで作った大きさを維持できているか。
- 肩から手まで力みすぎていないか。

## 6. 練習中のチェックリスト

自分が今練習している段階の項目を、振り返りに使ってください。

### スタートを練習しているとき

- [ ] ホバーを広げたときに、2個のディアボロが離れている。
- [ ] スタートで大きなミルを作ることを意識している。
- [ ] 「開く」「解く」の二段階でディアボロを上げている。

- [ ] 送った後に右手を引き戻し、次のディアボロを受け取っている。

### 回り始めたとき

- [ ] ミルの右下で受け、左へしっかり送り出している。
- [ ] スティックの先に力を伝える意識がある。
- [ ] スタートで作った大きさを維持できている。
- [ ] プッシュ数より、長く回すことを意識している。
- [ ] 力みすぎず、肩から手まで全体を使えている。

### 動きを見直すとき

- [ ] 自分の動画を撮り、「しているつもり」と実際の動きを見比べている。
- [ ] 参考動画と比較している。
- [ ] 自分に合う動きのイメージを言葉にしている。

WSのもう一つの目的は、一緒に練習する仲間を作ることでした。練習仲間と動きや感覚を話しながら、続けていきましょう。
